# Scurz FPS Plus

**An ongoing community update project by NotGriaz, based on the original resource pack by Scurz.**

Scurz FPS Plus is a Minecraft resource pack originally created by **Scurz**. This project aims to update and adapt the original pack for different Minecraft Java Edition versions while preserving credit to the original creator.

Currently, the pack supports **Minecraft Java Edition 1.20 and 1.20.1**. Work is ongoing to expand compatibility to more Minecraft versions.

## Current Compatibility

| Minecraft Edition | Version | Status |
|---|---|---|
| Java Edition | 1.20 | ✅ Supported |
| Java Edition | 1.20.1 | ✅ Supported |
| Java Edition | Other versions | 🚧 Planned / being worked on |

Future compatibility will depend on the necessary updates to the resource pack's files and assets. A version will be marked as supported once it has been updated and tested.

## Project Goals

- Expand compatibility to more Minecraft Java Edition versions.
- Update resource pack files when changes between Minecraft versions require it.
- Preserve the original creator's credit and the identity of the resource pack.
- Maintain a clear record of supported versions and project updates.
- Make the updated pack accessible to the Minecraft community.

## Installation

1. Download the resource pack ZIP from an available project release.
2. Launch Minecraft Java Edition.
3. Navigate to **Options → Resource Packs**.
4. Click **Open Pack Folder**.
5. Place the downloaded ZIP file into the folder.
6. Return to Minecraft and enable the resource pack.

Use a release that matches your Minecraft version. Do not assume compatibility with an unlisted version.
